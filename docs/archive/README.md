# Documentation archive

Documents in this directory are retained as historical evidence. They may
describe obsolete architecture, paths, commands or product decisions.

- `prototype-2026/` contains audits, milestone plans and implementation slices
  from the prototype phase.
- `handoffs/` contains proposals prepared for alternative deployment models.

Archive documents are not maintained and are excluded from canonical link and
metadata validation. Promote useful information by updating a current document
or recording a new ADR; do not edit history until it appears current.
